## Technical Standards & Structure
Every write-up within this repository strictly adheres to a 6-phase documentation methodology:
1. **Header / Title:** Categorization, platform source, and difficulty tier.
2. **Executive Summary:** Incident overview and primary core findings.
3. **Tools & Environment:** Utilities and platforms utilized during analysis.
4. **Step-by-Step Investigation:** Execution methodology, commands, and search queries.
5. **Identified IOCs & Artifacts:** Structured tables of indicators (hashes, IPs, domain names, file paths).
6. **Mitigation & Lessons Learned:** Defensive recommendations and SOC detection rules.
